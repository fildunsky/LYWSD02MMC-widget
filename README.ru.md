# LYWSD02MMC-widget

[English version](README.md)

Кроссплатформенный виджет для трея / строки меню, показывающий данные часов-гигрометра Xiaomi LYWSD02MMC. Работает на **Linux** (Ubuntu/GNOME), **Windows** и **macOS**, связывается с часами по Bluetooth LE и показывает:

- время на часах и его расхождение с системным, авто- и ручную синхронизацию
- температуру
- влажность
- комфорт — ту же «мордочку», что на экране часов: довольная, когда температура и влажность в зоне комфорта, грустная с причиной (холодно/жарко/сухо/влажно), когда нет. Мордочку можно показывать эмодзи (🙂/🙁) или в точности как на экране часов: `(^_^)` и `(-‸-)` — у e-ink дисплея два варианта глаз (`^`/`-`) и рта (`_`/`‸`), других состояний нет
- заряд батарейки

В трее может быть обычная иконка или сами показания: данные (`23.8°, 49%`), данные + мордашка, только мордашка, температура или влажность.

Зона комфорта по умолчанию — 19–27 °C и 20–85 % влажности (заводские пороги устройств miaomiaoce; у LYWSD02 они зашиты в прошивку и по BLE не настраиваются, поэтому виджет повторяет логику на своей стороне). Пороги можно поменять в конфиге, ключ `comfort`: `t_lo`, `t_hi`, `h_lo`, `h_hi`.

Опрос идёт раз в 10 минут (настраивается), пункт «Обновить сейчас» запрашивает данные немедленно. Часовой пояс выбирается из списка с городами, включая дробные пояса (Индия +05:30, Непал +05:45, Иран +03:30 и т.д.) — штатно часы такие показывать не умеют, виджет это обходит (см. «Протокол»). Языки интерфейса: русский и английский.

## Поддерживаемые устройства

Виджет работает с семейством e-ink часов-гигрометров производства Miaomiaoce (miaomiaoce.com), продающихся под брендами Xiaomi / Mijia. Официальные названия одной и той же железки в разных регионах:

| Модель | Официальное название |
|---|---|
| LYWSD02MMC | Xiaomi Temperature and Humidity Monitor Clock (глобальная версия, BHR5435GL); 米家电子温湿度计Pro (Китай) |
| LYWSD02 | Mijia Temperature and Humidity Electronic Watch — первое поколение, тот же протокол |
| MHO-C303 | Miaomiaoce Smart Clock — клон с будильником от того же производителя, тот же протокол |

Та же железка продаётся на Западе под именем Adafruit «Bluetooth eInk Display Clock with Temperature Humidity Sensor» (Adafruit 5023). Встроенный поиск находит устройства с именами `LYWSD02*` и `MHO-C303`; свои часы отличаются по уровню сигнала. На macOS система скрывает Bluetooth MAC-адреса и выдаёт вместо них UUID — встроенный поиск это полностью скрывает.

## Установка

Все файлы — на [странице релизов](../../releases). На любой платформе нужен Bluetooth-адаптер с BLE.

### Ubuntu / Linux

```sh
sudo apt install ./lywsd02-widget_*_all.deb
```

Зависимости подтянутся из репозиториев Ubuntu автоматически. Нужен GNOME с расширением `ubuntu-appindicators` (в Ubuntu включено из коробки). Запуск: «LYWSD02 Widget» в меню приложений.

### Windows 10+

Скачайте `lywsd02-widget.exe` и просто запустите — установка не нужна. SmartScreen может предупредить о неподписанном файле — «Подробнее → Выполнить в любом случае».

### macOS

Скачайте `lywsd02-widget-macos-arm64.zip` (Apple Silicon), распакуйте и запустите через правый клик → «Открыть» (приложение не подписано), затем разрешите доступ к Bluetooth. На Intel-маках — из исходников:

```sh
pip3 install bleak rumps pillow && python3 mac/lywsd02_widget_mac.py
```

### Из исходников (Linux)

```sh
git clone https://github.com/fildunsky/LYWSD02MMC-widget.git
cd LYWSD02MMC-widget
./install.sh
./run.sh
```

Скрипт создаёт виртуальное окружение `.venv` с [bleak](https://github.com/hbldh/bleak), при отсутствии `gir1.2-ayatanaappindicator3-0.1` добывает typelib через `apt-get download` (без root) и прописывает ярлык в меню приложений и автозапуск.

Сборка пакетов: `./package/build-deb.sh [версия]` собирает `.deb` в `dist/`; workflow'ы `windows-build` и `macos-build` в GitHub Actions собирают `win/lywsd02_widget_win.py` и `mac/lywsd02_widget_mac.py` и прикладывают бинарники к релизу.

## Настройки

Пункт «Настройки» (окно на Linux/Windows, подменю выпадашки на macOS):

- **Язык** — русский или английский, применяется сразу
- **Часы** — поиск: виджет сканирует эфир и показывает найденные устройства с адресом и уровнем сигнала; выбор строки сразу переключает на это устройство и опрашивает его
- **Опрос** — период опроса в минутах
- **Часовой пояс** — «Системный» или фиксированный офсет в формате «(UTC+03:00) Москва, Стамбул, Эр-Рияд», включая дробные пояса; записывается в часы при синхронизации
- **Мордочка** — эмодзи или текстовая, как на часах
- **В трее** — что показывать в панели / строке меню
- **Автозапуск при входе**
- **Автосинхронизация времени** — при каждом опросе, если часы разошлись с системой больше чем на 10 секунд или пояс не совпадает (включена по умолчанию)
- **Синхронизировать время сейчас**

Переменные окружения `LYWSD02_MAC` и `LYWSD02_POLL` работают как фолбэк, если в конфиге значений нет.

## Протокол

Стандартные GATT-характеристики LYWSD02 (сервис `EBE0CCB0-...`):

| UUID | Данные |
|---|---|
| `EBE0CCB7-7A0A-4B0C-8A1A-6FF2997DA3A6` | время: uint32 LE (unix) + int8 смещение пояса |
| `EBE0CCC1-7A0A-4B0C-8A1A-6FF2997DA3A6` | notify: int16 LE температура ×0.01 °C + uint8 влажность % |
| `EBE0CCC4-7A0A-4B0C-8A1A-6FF2997DA3A6` | uint8 заряд батарейки % |

Прошивка часов хранит пояс одним байтом в целых часах, поэтому «из коробки» дробные пояса они показывать не умеют. Виджет обходит это так: в байт пишется пояс, округлённый вниз до часа, а остаток (30/45 минут) прибавляется к записываемому epoch — на экране получается правильное местное время.

## Удаление

- Linux (пакет): `sudo apt remove lywsd02-widget`
- Linux (исходники): `rm ~/.config/autostart/lywsd02-widget.desktop ~/.local/share/applications/lywsd02-widget.desktop`
- Windows: удалите exe; автозапуск убирается галкой «Автозапуск при входе» в настройках
- macOS: удалите приложение; автозапуск убирается той же галкой (LaunchAgent `org.lywsd02.widget`)
